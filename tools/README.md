# tools

SPECIFICATION_PHONOLOGY.md の検証に使う道具です。どちらも Python 3 の標準ライブラリだけで動きます。

## phonology_check.py（誤り検出の総当たり）

1.4「保証の述べ方と確かめ方」で定めた総当たりの道具です。

```
python3 tools/phonology_check.py --model alpha --final-stress
```

- `--model`：語の形の規則（課題39の語の境目の候補）。`alpha`（α）、`alpha_prime`（α′）、`beta`（β）、`beta_prime`（β′）。
- `--final-stress`：強勢を語末の音節に置く場合に付けます。C2（t→l）の適用範囲が変わります。
- `--examples N`：区切りが変わる例を、誤りごとに N 個まで表示します。

### 入力

1. 文字単位の集合（2.5）：`build_chunks` が 2.3・2.5 の規則から37マスを作ります。
2. 語の形の規則：`MODELS`。どの候補でも、語の境目は各文字単位の種類だけで決まります。
3. 誤りの規則：`RULES`。1.5.3の一覧の番号と、1.5.4の担当を添えています。一覧や担当を変えたときは、ここも直します。

| 規則 | 一覧の番号 | 書き換え |
| --- | --- | --- |
| A2 | A2 | 共鳴音の後の /i/・/u/ を消す |
| A3 | A3 | 語末の母音を消す |
| A3+聞き取り | A3・E10 | 語末の母音を消し、閉鎖音＋/h/ を有気の閉鎖音1つ（/h/ なし）とする |
| A2・A3+E3 | A2・A3・E3 | 母音を消し、並んだ同じ子音を1つにする（長さを区別しない聞き手） |
| A2・A3+E10 | A2・A3・E10 | 母音を消し、子音の前で聞こえなくなる /h/・/j/・/w/ も消す |
| A3+E10（閉鎖音） | A3・E10 | 語末の母音を消し、次の子音の前で破裂が聞こえなくなる /p/・/t/・/k/ も消す（推測による経路） |
| A4 | A4 | 隣り合う同じ文字単位の一方を消す |
| 文字単位の脱落・挿入 | ― | 文字単位を1つ消す・1つ加える |
| B1 | B1 | 母音を別の母音に替える（曖昧母音への弱化の近似） |
| B2 | B2 | e と i、o と u を入れ替える |
| C2（t→l） | C2 | 語中の、強勢のない母音の前の /t/ を /l/ に替える |
| C2・E9（p→w） | C2・E9 | 母音の間の /p/ を /w/ に替える |
| C3 | C3 | /j/・/w/ を消す |
| C4 | C4 | /h/ を消す |
| E1 | E1 | /p/・/t/・/k/ どうし、/m/・/n/ どうしを入れ替える |
| E2 | E2 | /s/ と /h/ を入れ替える |

一覧のうち、2.5の設計では生じない項目（1.5.4）と、音素の置き換えで近似できない B4 は規則にしていません。B4 の影響は B1 の近似に含まれます。

### 出力

誤りごとに、結果を次の3つに分けた件数を表示します。

- **非文**：どの文字単位にも分けられないか、語の形の規則に合わない。誤りとして検出できます。
- **同じ区切り**：正しい列のままで、語の区切りは変わらない。別の語になります。
- **区切りの違い**：正しい列のままで、語の区切りが変わる。検出できません。

担当が「音韻」または「境目の条件」の誤りで「区切りの違い」が0件でなければ、「要件に反する」と表示します。その場合は、1.4の例外として記録するか、設計を直します。担当が「文法・語彙」の誤りは、件数を報告するだけです。

### 総当たりの範囲と、それで十分である理由

誤りを当てる2つの隣り合う文字単位（内側）は、37×37通りをすべて調べます。その前後の文脈は、代表の文字単位（`ka`・`ma`・`mi`）で補います。文章の先頭と末尾も、別に調べます。これで十分である理由は次のとおりです。

1. どの誤りの規則も、書き換えるのは隣り合う2つの文字単位の範囲の中だけです。どの2つの文字単位も、いずれかの窓で内側になります。
2. 文字単位はすべて CV なので、書き換えの後の列がどの文字単位にも分けられるかは、書き換えた所とその両隣の音素だけで決まります。
3. 候補 α・α′・β・β′ では、語の境目は各文字単位の種類（阻害音で始まるか、狭い母音を含むか、前舌母音を含むか）だけで決まります。文脈の文字単位で効くのは種類だけです。代表の `ka`（阻害音・後舌）、`ma`（共鳴音・後舌）、`mi`（共鳴音・前舌・狭い母音）は、各候補で区切りを決める種類の値をすべて含みます（α・α′ では阻害音か共鳴音か、β では狭い母音か、β′ では前舌か後舌か）。

このため、件数は「内側を総当たりし、文脈を代表で補って数えた値」です。実際の文章での起こりやすさの割合ではありません。区切りが変わる場合が1件でもあるかどうかの判定に使います。

新しい語の形の規則を加えるときは、3が成り立つかを確かめます。境目が文字単位の種類だけで決まらない規則では、この論証は使えません。

## phoible_stats.py（PHOIBLE の集計）

2.3・2.4に記した、子音や母音の体系を持つ言語の割合を再現します。

```
python3 tools/phoible_stats.py --download phoible.csv   # データを取得して集計
python3 tools/phoible_stats.py phoible.csv              # 取得済みのデータで集計
```

データ（PHOIBLE の data/phoible.csv、約26MB）はリポジトリに含めません。集計の方法はスクリプトの冒頭に記しています。
